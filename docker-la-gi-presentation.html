Cách đóng gói ứng dụng để chạy nhất quán từ máy developer đến server và cloud.

01 · Vấn đề

“Máy tôi chạy được mà?”

💻

Máy Developer

Python 3.12, đúng package, đúng biến môi trường → chạy tốt.

🖥️

Máy Server

Python khác phiên bản, thiếu dependency, config khác → có thể lỗi.

Docker giúp chuẩn hóa môi trường chạy của ứng dụng.

03 · 3 khái niệm quan trọng

Dockerfile → Image → Container

📄

Dockerfile

📦

Docker Image

🚀

Một instance đang chạy của image.

Dockerfile
build →

Container
04 · Ví dụ

Đóng gói FastAPI bằng Docker

main.py
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def hello():
    return {"message": "Hello VLearn"}
Dockerfile
FROM python:3.12

WORKDIR /app

COPY . .

RUN pip install -r requirements.txt

CMD ["uvicorn", "main:app",
     "--host", "0.0.0.0",
     "--port", "8000"]
05 · Build & Run

Chỉ cần 2 bước

1. Build image

docker build -t vlearn-api .

Tạo image có tên vlearn-api.

2. Run container

docker run -p 8000:8000 vlearn-api

Ứng dụng chạy tại localhost:8000.

08 · Docker Compose

Bật cả hệ thống bằng một lệnh

services:
  backend:
    build: ./backend

  frontend:
    build: ./frontend

  database:
    image: postgres

  redis:
    image: redis

Chạy toàn bộ

docker compose up

Docker Compose giúp quản lý nhiều container trong cùng một ứng dụng.
